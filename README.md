# Paradox Interactive Music MOD Support Tool (OGG File Renamer)

Paradox Interactive製ゲーム（HoI4, EU4, CK3等）の音楽MOD作成を支援するツールです。
日本語の音楽ファイルをゲームで扱える形式に一括リネームし、元の日本語タイトルを表示するためのローカライズファイルを自動生成します。

## 🌟 主な機能

- **自動ローマ字変換**: 日本語（漢字・ひらがな・カタカナ）のファイル名を、ゲーム内で認識可能な英数字（ローマ字）に一括変換します。
- **文字数チェック**: ファイル名が長すぎるとゲーム内で認識されない問題を防ぐため、制限（デフォルト63文字）を超えた場合に警告を表示します。
- **プレビュー・手動編集**: 実行前に変換後のファイル名を一覧で確認でき、必要に応じて直接ダブルクリックして編集可能です。
- **YAML生成**: 変換前後のファイル名を紐付けた `_l_japanese.yml`（ローカライズファイル）を自動生成します。これにより、ゲーム内では元の日本語タイトルが正しく表示されます。
- **安全なコピー**: 元ファイルを直接操作せず、指定したフォルダにリネームしたコピーを作成します。

## 🚀 使い方

1. **ファイル読み込み**: 「フォルダを選択」または「ファイルを選択」から対象のOGGファイルを読み込みます。
2. **プレビューと確認**:
   - 一覧に表示された「変換後のファイル名」を確認します。
   - 赤くハイライトされている行は文字数制限を超えています。ダブルクリックして短く修正してください。
3. **リネーム実行**: 「リネーム実行」ボタンを押すと、出力フォルダに変換後のOGGファイルと `_l_japanese.yml` が生成されます。
4. **仕上げ**:
   - 生成されたファイルをMODの `music` フォルダ等に配置します。
   - 音楽の定義（.txtファイル等）の作成には、以下のツールを併用するとスムーズです。
     - [Music Mod Creation Tool](https://runite-drill.github.io/music-mod-creation-tool/)

## 🛠 動作環境

- Python 3.10以上推奨
- 依存ライブラリ:
  - `pykakasi` (ローマ字変換用)
  - `PyYAML` (YAML生成用)
  - `tkinter` (標準GUIライブラリ)
